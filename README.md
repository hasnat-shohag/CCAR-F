# CCAR-F বাংলা স্টাডি গাইড

[![Deploy site to GitHub Pages](https://github.com/hasnat-shohag/CCAR-F/actions/workflows/deploy.yml/badge.svg)](https://github.com/hasnat-shohag/CCAR-F/actions/workflows/deploy.yml)

Claude Certified Architect (Foundations) — **CCAR-F** পরীক্ষার জন্য বাংলা স্টাডি সাইট। ৫টি ডোমেইন, ৩০টি লেসন, কীওয়ার্ড টেবিল, Mermaid ডায়াগ্রাম, পরীক্ষার ফাঁদ আর ব্রাউজারে-সংরক্ষিত অগ্রগতি ট্র্যাকার।

**লাইভ সাইট:** https://hasnat-shohag.github.io/CCAR-F/

- সব লেসন বাংলায়, কিন্তু প্রযুক্তিগত শব্দ (`stop_reason`, `MCP`, `CLAUDE.md`, `PreToolUse`) ইংরেজিতেই — GitHub কোড খুঁজে পাওয়ার মতো।
- প্রতি লেসনে: বাংলা ব্যাখ্যা, মূল কীওয়ার্ড টেবিল, ডায়াগ্রাম, পরীক্ষার ফাঁদ, প্র্যাকটিস সিনারিও আর বিল্ড এক্সারসাইজ।
- সাইডবারে ✓ চিহ্ন আর `/progress/` ড্যাশবোর্ডে ডোমেইনভিত্তিক প্রগ্রেস বার।
- ডোমেইন অনুযায়ী অ্যাকসেন্ট রং (নীল, টিল, অ্যাম্বার, ভায়োলেট, রোজ) ও ডার্ক/লাইট থিম।

## দ্রুত শুরু

```bash
pnpm install          # Node 22+, pnpm 11+
pnpm dev              # http://localhost:4321/CCAR-F/
pnpm check            # astro check (টাইপ + কনটেন্ট স্কিমা)
pnpm build            # dist/ তৈরি করে
pnpm check:links      # dist/ বিল্ডের পর ভেতরের লিংক যাচাই
pnpm preview          # বিল্ড করা সাইট লোকালি দেখুন
```

অনুবাদ না হওয়া লেসনের লিংক "pending" হিসেবে দেখায় (`--verbose` দিলে তালিকাসহ), আর সত্যিকারের ভাঙা লিংক শূন্য না হলে কমান্ড ফেল করে।

মূল ইংরেজি পাঠ ডাউনলোড করে অনুবাদের রেফারেন্স বানাতে (শুধু ডেভেলপারদের জন্য, আউটপুট `tools/.source/`, gitignored):

```bash
pnpm fetch-source                       # সব লেসন
pnpm fetch-source 1-1-agentic-loops     # নির্দিষ্ট লেসন
pnpm fetch-source --force               # পুরনো ফাইল আবার নামান
```

## লেসন লেখার নিয়ম

প্রতিটি লেসন `src/content/docs/learn/<domain-slug>/<task-slug>.mdx`, স্লাগ মূল সাইটের মতোই রাখা হয় (যেমন `1-1-agentic-loops`)।

```yaml
---
title: এজেন্টিক লুপ          # বাংলা শিরোনাম (h1)
titleEn: Agentic Loops        # ইংরেজি নাম
domain: 1                     # 1-5 (থিম অ্যাকসেন্ট ঠিক করে)
task: "1.1"
order: 1
sourceUrl: https://claudecertificationguide.com/learn/1-agentic-architecture/1-1-agentic-loops
updated: 2026-09-12
keywords:                     # কীওয়ার্ড টেবিল
  - term: stop_reason
    bn: বাংলা অর্থ
    tip: পরীক্ষার টিপ
sources:                      # নিচে সোর্স লিস্ট
  - label: Messages API Reference
    href: https://docs.anthropic.com/en/api/messages
---
```

লেসনের বডি শেষ হবে `<Attribution sourceUrl={frontmatter.sourceUrl} />` আর `<MarkComplete lessonId="1-1" />` দিয়ে। ডায়াগ্রাম Mermaid ব্লকে লিখুন — সাইট ও GitHub দুটোতেই রেন্ডার হয়।

## অগ্রগতি ট্র্যাকিং যেভাবে কাজ করে

- সব অগ্রগতি ব্রাউজারের `localStorage`-এ একটিমাত্র key-তে: `ccarf:v1`।
- অগ্রগতি = সম্পন্ন চিহ্নিত লেসন ÷ ৩০। শুধু লেসনের নিচের **সম্পন্ন হয়েছে** বোতামে চাপ দিলেই গণনা হয়; স্ক্রল করলে কিছু হয় না।
- পরিসংখ্যান: সাইডবারে ✓, স্ক্রল প্রগ্রেস বার (শুধু দেখার জন্য), ড্যাশবোর্ডে ডোমেইনভিত্তিক বার।
- কোনো অ্যাকাউন্ট, সার্ভার বা ডেটাবেস নেই — তাই এক ব্রাউজার থেকে আরেক ব্রাউজারে অগ্রগতি যায় না। ডেটা নষ্ট হলে অ্যাপ চুপচাপ রিসেট করে, ভাঙে না।

## ডিপ্লয়

`main`-এ পুশ করলেই Actions সাইট বিল্ড করে Pages-এ দেয়।

**একবারের সেটআপ (GitHub UI থেকে, কেউ কোড দিয়ে করতে পারবে না):**

1. Settings → General → Default branch = **main** (রিপোতে `master` branch-ও থাকলে সেটি `main`-এর সমান রাখা হয়েছে)।
2. Settings → Pages → Source = **GitHub Actions**। Actions-এর `GITHUB_TOKEN` দিয়ে Pages চালু করা যায় না, তাই এই ধাপটি হাতে করতে হয় — না করলে ডিপ্লয় ওয়ার্কফ্লো `Configure Pages` ধাপে থেমে যায়।

**এরপর প্রতিবার:** `main`-এ পুশ করলেই সাইট বিল্ড হয়ে ডিপ্লয় হয়, অথবা Actions থেকে `workflow_dispatch` চালান।

- URL: https://hasnat-shohag.github.io/CCAR-F/ — base path `/CCAR-F`, তাই `astro.config.mjs`-এর `base` বদলালে আগে `.github/workflows/deploy.yml`-ও মিলিয়ে নিন।
- CI ধাপ: install → `pnpm check` → `pnpm build` → `pnpm check:links` → Pages আর্টিফ্যাক্ট আপলোড → ডিপ্লয়।

## কনট্রিবিউট

PR স্বাগত — বিশেষ করে অনুবাদ সংশোধন। নিয়মগুলো [CONTRIBUTING.md](./CONTRIBUTING.md) তে। দ্রুত সংস্করণ:

1. পরিবর্তন ছোট রাখুন (প্রতি PR-এ একটি লেসন বা একটি কম্পোনেন্ট)।
2. প্রযুক্তিগত শব্দ ইংরেজিতে রাখুন; নতুন শব্দ আগে `glossary-terms.json`-এ যোগ করুন।
3. `pnpm check` আর `pnpm build` পাস করতে হবে।
4. অনুবাদে ভুল ধরা পড়লে issue খুলুন — কোন বাক্য, কেন ভুল, সঠিক কী হওয়া উচিত।
