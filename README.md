Claude Certified Architect (Foundations) — **CCAR-F** পরীক্ষার জন্য বাংলা স্টাডি সাইট। ৫টি ডোমেইন, ৩০টি লেসন, ডোমেইনভিত্তিক রিভিশন শিট, পরীক্ষা গাইড, কীওয়ার্ড টেবিল, Mermaid ডায়াগ্রাম, পরীক্ষার ফাঁদ আর ব্রাউজারে-সংরক্ষিত অগ্রগতি ট্র্যাকার।

**লাইভ সাইট:** https://hasnat-shohag.github.io/CCAR-F/

- সব লেসন বাংলায়, কিন্তু প্রযুক্তিগত শব্দ (`stop_reason`, `MCP`, `CLAUDE.md`, `PreToolUse`) ইংরেজিতেই — GitHub কোড খুঁজে পাওয়ার মতো।
- প্রতি লেসনে: বাংলা ব্যাখ্যা, মূল কীওয়ার্ড টেবিল, ডায়াগ্রাম, পরীক্ষার ফাঁদ, প্র্যাকটিস সিনারিও আর বিল্ড এক্সারসাইজ।
- সাইডবারে ✓ চিহ্ন আর `/progress/` ড্যাশবোর্ডে ডোমেইনভিত্তিক প্রগ্রেস বার।
- `/quick-reference/`-এ প্রতি ডোমেইনের এক-পাতার রিভিশন শিট (প্রিন্ট-বান্ধব) আর `/exam-guide/`-এ পরীক্ষার ফরম্যাট, ৬টি সিনারিও, ওয়েট ও পাসের নিয়ম।
- ডোমেইন অনুযায়ী অ্যাকসেন্ট রং (নীল, টিল, অ্যাম্বার, ভায়োলেট, রোজ) ও ডার্ক/লাইট থিম।

## দ্রুত শুরু

```bash
pnpm install          # Node 22+, pnpm 11+
pnpm dev              # http://localhost:4321/CCAR-F/
pnpm check            # astro check (টাইপ + কনটেন্ট স্কিমা)
pnpm build            # dist/ তৈরি করে
pnpm check:links      # dist/ বিল্ডের পর ভেতরের লিংক যাচাই
pnpm check:contrast   # dist/ বিল্ডের পর কনট্রাস্ট যাচাই (হেডলেস Chrome দরকার)
pnpm preview          # বিল্ড করা সাইট লোকালি দেখুন
```

অনুবাদ না হওয়া লেসনের লিংক "pending" হিসেবে দেখায় (`--verbose` দিলে তালিকাসহ), আর সত্যিকারের ভাঙা লিংক শূন্য না হলে কমান্ড ফেল করে।

`check:contrast` বিল্ড করা `dist/` হেডলেস Chrome-এ খুলে টার্ম-কলাম, টেবিলের কোড, সাধারণ লিংক আর সাইডবারের বর্তমান এন্ট্রির **computed** রং মাপে — অর্থাৎ Starlight-এর cascade হাতে মডেল না করে পাঠক যা দেখবে ঠিক সেটাই। রং সীমার নিচে নামলে কমান্ড ফেল করে। Chrome না থাকলে `--allow-missing-browser` দিলে চেকটি স্কিপ হয় (`CHROME_PATH` দিয়ে ব্রাউজার পাথ দেওয়া যায়)।

মূল ইংরেজি পাঠ ডাউনলোড করে অনুবাদের রেফারেন্স বানাতে (শুধু ডেভেলপারদের জন্য, আউটপুট `tools/.source/`, gitignored):

```bash
pnpm fetch-source                       # সব লেসন
pnpm fetch-source 1-1-agentic-loops     # নির্দিষ্ট লেসন
pnpm fetch-source --force               # পুরনো ফাইল আবার নামান
```

## লেসন লেখার নিয়ম

প্রতিটি লেসন `src/content/docs/learn/<domain-slug>/<task-slug>.mdx`, স্লাগ মূল সাইটের মতোই রাখা হয় (যেমন `1-1-agentic-loops`)।

```yaml
---
title: এজেন্টিক লুপ          # বাংলা শিরোনাম (h1)
titleEn: Agentic Loops        # ইংরেজি নাম
domain: 1                     # 1-5 (থিম অ্যাকসেন্ট ঠিক করে)
task: "1.1"
order: 1
sourceUrl: https://claudecertificationguide.com/learn/1-agentic-architecture/1-1-agentic-loops
updated: 2026-09-12
keywords:                     # কীওয়ার্ড টেবিল
  - term: stop_reason
    bn: বাংলা অর্থ
    tip: পরীক্ষার টিপ
sources:                      # নিচে সোর্স লিস্ট
  - label: Messages API Reference
    href: https://docs.anthropic.com/en/api/messages
---
```

লেসনের বডি শেষ হবে `<Attribution sourceUrl={frontmatter.sourceUrl} />` আর `<MarkComplete lessonId="1-1" />` দিয়ে। ডায়াগ্রাম Mermaid ব্লকে লিখুন — সাইট ও GitHub দুটোতেই রেন্ডার হয়।

**ভেতরের লিংক কখনো খালি `/learn/` আকারে লিখবেন না।** Astro MDX বা Starlight hero action-এর লিংকে `base` যোগ করে না, তাই `/learn/` ডিপ্লয়ে ডোমেইন-রুটে গিয়ে ৪০৪ খায়। MDX-এ `siteUrl()` ইমপোর্ট করে লিখুন — `<a href={siteUrl('learn/')}>সিলেবাস</a>` (হিরো অ্যাকশনের লিংকে base হাতে লিখতে হয়, কারণ frontmatter থেকে `siteUrl()` কল করা যায় না)। `pnpm check:links` base ছাড়া লিংক ভাঙা হিসেবে ধরে।

## অগ্রগতি ট্র্যাকিং যেভাবে কাজ করে

- সব অগ্রগতি ব্রাউজারের `localStorage`-এ একটিমাত্র key-তে: `ccarf:v1`।
- অগ্রগতি = সম্পন্ন চিহ্নিত লেসন ÷ ৩০। শুধু লেসনের নিচের **সম্পন্ন হয়েছে** বোতামে চাপ দিলেই গণনা হয়; স্ক্রল করলে কিছু হয় না।
- পরিসংখ্যান: সাইডবারে ✓, স্ক্রল প্রগ্রেস বার (শুধু দেখার জন্য), ড্যাশবোর্ডে ডোমেইনভিত্তিক বার।
- কোনো অ্যাকাউন্ট, সার্ভার বা ডেটাবেস নেই — তাই এক ব্রাউজার থেকে আরেক ব্রাউজারে অগ্রগতি যায় না। ডেটা নষ্ট হলে অ্যাপ চুপচাপ রিসেট করে, ভাঙে না।

**টার্ম-কলামের কনট্রাস্ট ঠিক করা হয়েছে:** আগে টার্ম-কলাম `--sl-color-text-accent` ব্যবহার করত, যা Starlight লাইট থিমে ডোমেইনের মূল অ্যাকসেন্টে নামায় — D3-এ ৩.১৯:১, D2-তে ৩.৭৪:১ (৪.৫:১-এর নিচে)। এখন `.keyword-table .keyword-term` ও `.ref-table` হাই-কনট্রাস্ট `--sl-color-accent-high` ব্যবহার করে, যা লাইটে গাঢ় শেড আর ডার্কে হালকা শেড দেয় — তাই গ্লোসারি, ৩০টি লেসন ও ৫টি শিটে কনট্রাস্ট এখন লাইটে ৭.০৯–১৩.৫২:১, ডার্কে ১০.৫৮–১৪.২৪:১। সঙ্গে টেবিলের inline code আর `.progress-hint code`-ও ঠিক করা হয়েছে (ডার্কে আগে ৩.৪৮:১ ছিল)।

**সাইডবারের বর্তমান পাতার লিংকও ঠিক করা হয়েছে:** Starlight বর্তমান এন্ট্রিকে raw accent দিয়ে ভরাট pill বানায় আর তার উপরে inverse ফোরগ্রাউন্ড বসায়। সাইটের আগের নিয়ম (`a[data-lesson-id][aria-current='page']`, specificity-তে Starlight-এর `:where()` নিয়মের চেয়ে এগিয়ে) সেটিকে accent-এর উপরে accent করে ফেলত — অর্থাৎ লেসন পাতায় সাইডবারের বর্তমান লেসনের নাম **সম্পূর্ণ অদৃশ্য ছিল (১:১)**, লাইট-ডার্ক দুটোতেই। এখন pill ভরে `--sl-color-accent-high`, ফোরগ্রাউন্ড Starlight-এর `--sl-color-text-invert`, আর pill-এর ভেতরের ✓ নেয় pill-এর নিজের রং। ১০টি পাতা × ২ viewport × ২ থিমে যাচাই: ৬.৭৮–১৩.৫২:১।

**এখনো বাকি (আলাদা সিদ্ধান্ত):** কনটেন্টের সাধারণ লিংক (`.sl-markdown-content a`) এখনও Starlight-এর `--sl-color-text-accent` ব্যবহার করে, তাই লাইট থিমে D3-এ ৩.১৯:১ ও D2-তে ৩.৭৪:১ — ৪.৫:১-এর নিচে। এটি ঠিক করতে `--sl-color-text-accent` নিজেই বদলাতে হবে, যা সাইটের সব লিংকের রং বদলাবে — তাই আলাদা করে সিদ্ধান্ত নেওয়া ভালো।

**কনট্রাস্ট আর নীরবে ভাঙতে পারবে না:** `pnpm check:contrast` বিল্ড করা `dist/` হেডলেস Chrome-এ খুলে ৭টি পাতা (প্রতি ডোমেইনের একটি + গ্লোসারি + exam guide) × ২ থিমে **computed** রং মাপে। লক্ষ্য: টার্ম-কলাম, টেবিলের কোড, প্রসের কোড ও সাইডবারের বর্তমান এন্ট্রি (৪.৫:১), আর গ্রাফিক মার্কার হিসেবে ✓ চিহ্ন (৩:১)। Starlight-এর cascade হাতে মডেল করা হয় না, তাই টোকেন বদলালেই ঠিক পাঠকের চোখে যা পড়ে সেটাই মাপা হয়; একটি টোকেনই কমে গেলে কমান্ড ফেল করে। `tools/check-contrast.mjs`-এর `KNOWN_GAPS` মানচিত্রে আগের ঋণ (লাইট থিমে কনটেন্টের সাধারণ লিংক) লেখা আছে — শুধু কমে, বাড়ে না; মান সীমা ছুঁলে এন্ট্রিটি মুছে ফেলার কথা স্ক্রিপ্ট নিজেই মনে করিয়ে দেয়। এ কারণেই এই চেকটি CI-তে চলে (GitHub-এর রানার ইমেজে Chrome থাকে)।

**ছোট একটি বাকি:** সম্পন্ন কিন্তু বর্তমান নয় — এমন লেসনের ✓ চিহ্ন (`a[data-lesson-id].is-complete::after`) এখনও raw accent ব্যবহার করে, লাইট থিমে D3-এ ৩.১৯:১ (গ্রাফিকের ৩:১ সীমা পাস করে, টেক্সটের ৪.৫:১ নয়)। দরকার হলে টার্ম-কলামের মতো এক লাইনে `--sl-color-accent-high`-এ নেওয়া যায়।

## ডিপ্লয়

`main`-এ পুশ করলেই Actions সাইট বিল্ড করে Pages-এ দেয়।

**একবারের সেটআপ (GitHub UI থেকে, কেউ কোড দিয়ে করতে পারবে না):**

1. Settings → General → Default branch = **main** (রিপোতে `master` branch-ও থাকলে সেটি `main`-এর সমান রাখা হয়েছে)।
2. Settings → Pages → Source = **GitHub Actions**। Actions-এর `GITHUB_TOKEN` দিয়ে Pages চালু করা যায় না, তাই এই ধাপটি হাতে করতে হয় — না করলে ডিপ্লয় ওয়ার্কফ্লো `Configure Pages` ধাপে থেমে যায়।

**এরপর প্রতিবার:** `main`-এ পুশ করলেই সাইট বিল্ড হয়ে ডিপ্লয় হয়, অথবা Actions থেকে `workflow_dispatch` চালান।

- URL: https://hasnat-shohag.github.io/CCAR-F/ — base path `/CCAR-F`, তাই `astro.config.mjs`-এর `base` বদলালে আগে `.github/workflows/deploy.yml`-ও মিলিয়ে নিন।
- CI ধাপ: install → `pnpm check` → `pnpm build` → `pnpm check:links` → `pnpm check:contrast` → Pages আর্টিফ্যাক্ট আপলোড → ডিপ্লয়।

PR স্বাগত — বিশেষ করে অনুবাদ সংশোধন। নিয়মগুলো [CONTRIBUTING.md](./CONTRIBUTING.md) তে। দ্রুত সংস্করণ:
