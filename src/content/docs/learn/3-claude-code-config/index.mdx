ডেভেলপমেন্ট ওয়ার্কফ্লোর জন্য Claude Code কনফিগার করা — CLAUDE.md, স্ল্যাশ কমান্ড, Skills, পারমিশন, হুক ও CI/CD ইন্টিগ্রেশন।

## এই ডোমেইনে যা আসে

- CLAUDE.md হায়ারার্কি, স্কোপিং ও মডুলার অর্গানাইজেশন
- কাস্টম স্ল্যাশ কমান্ড ও Skills দিয়ে পুনরাবৃত্ত কাজ কমানো
- পাথ-ভিত্তিক নিয়মে কন্ডিশনাল কনভেনশন লোড করা
- প্ল্যান মোড বনাম সরাসরি এক্সিকিউশন — কখন কোনটি
- ইটারেটিভ রিফাইনমেন্ট ও CI/CD পাইপলাইনে Claude Code
