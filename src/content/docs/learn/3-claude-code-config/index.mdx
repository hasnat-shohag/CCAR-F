- কাস্টম slash command ও Skills দিয়ে পুনরাবৃত্ত কাজ কমানো
- পাথ-ভিত্তিক নিয়মে কন্ডিশনাল কনভেনশন লোড করা
- plan mode বনাম সরাসরি এক্সিকিউশন — কখন কোনটি
- ইটারেটিভ রিফাইনমেন্ট ও CI/CD পাইপলাইনে Claude Code
