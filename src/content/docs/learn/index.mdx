Claude Certified Architect (Foundations) পরীক্ষায় ৫টি ডোমেইন, মোট ৩০টি টাস্ক স্টেটমেন্ট। ওয়েট আলাদা, তাই পড়ার সময়ও ভাগ করে নিন। পরীক্ষা ৬০ প্রশ্ন, ১২০ মিনিট, পাস ৭২০/১০০০, ক্রেডেনশিয়াল ১২ মাস — সিলেবাস v1.0, জুলাই ২০২৬।

## পড়ার ক্রম যেভাবে ঠিক করবেন

- **প্রথমে D1 (২৭%)** — এজেন্টিক লুপ আর অর্কেস্ট্রেশন বুঝলে বাকি ডোমেইনের ভিত্তি তৈরি হয়। এখানেই সবচেয়ে বেশি প্রশ্ন আসে।
- **তারপর D3 ও D4 (প্রতিটি ২০%)** — Claude Code কনফিগারেশন এবং প্রম্পট ইঞ্জিনিয়ারিং বাস্তবে সবচেয়ে বেশি ব্যবহার হয়, প্রশ্নও বেশি।
- **এরপর D2 (১৮%)** — টুল ডিজাইন ও MCP; D1-এর সাথে মিলে যাওয়া ধারণা অনেক।
- **শেষে D5 (১৫%)** — কনটেক্সট ম্যানেজমেন্ট ও রিলায়েবিলিটি; ছোট ওয়েট, কিন্তু সিনারিও প্রশ্নে প্রায়ই আসে।
