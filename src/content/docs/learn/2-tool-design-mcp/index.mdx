এফেক্টিভ টুল স্কিমা ডিজাইন, MCP সার্ভার ও ক্লায়েন্ট বাস্তবায়ন, আর বাইরের সার্ভিস Claude-ভিত্তিক অ্যাপে যুক্ত করা।

## এই ডোমেইনে যা আসে

- টুলের নাম, বর্ণনা ও বাউন্ডারি এমনভাবে লেখা যাতে মডেল ঠিক টুল বাছে
- MCP টুলের জন্য স্ট্রাকচার্ড এরর রেসপন্স ও রিকভারি মেটাডেটা
- একাধিক এজেন্টে টুল ভাগ করা ও `tool_choice` কনফিগার করা
- Claude Code ও এজেন্ট ওয়ার্কফ্লোতে MCP সার্ভার স্কোপ ও ইন্টিগ্রেশন
- বিল্ট-ইন টুল কখন ব্যবহার করবেন, কাস্টম টুল কখন
