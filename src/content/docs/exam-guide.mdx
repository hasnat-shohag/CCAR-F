Claude Certified Architect (Foundations), কোড **CCAR-F** — Anthropic-এর চারটি সার্টিফিকেশনের মধ্যে এটিই একমাত্র **scenario-ভিত্তিক**। সেই ফরম্যাটই বলে দেয় আসলে কী যাচাই করা হয়: ডকুমেন্ট মুখস্থ আছে কি না নয়, বরং বাস্তব পরিস্থিতিতে একাধিক যুক্তিসঙ্গত অপশনের সামনে সঠিক আর্কিটেকচারাল সিদ্ধান্ত নিতে পারেন কি না।

তাক করা প্রার্থী সে-ই, যে সত্যিই Claude দিয়ে কিছু শিপ করেছে — ডকুমেন্ট পড়ে শেখা নয়। গাইড মোটামুটি ছয় মাসের ব্যবহারিক অভিজ্ঞতা ধরে নেয়: Claude API, Agent SDK, Claude Code আর MCP জুড়ে।

## পরীক্ষার ফরম্যাট: ৬টির ব্যাংক থেকে ৪টি সিনারিও

বেশিরভাগ সার্টিফিকেশন পরীক্ষা বিচ্ছিন্ন প্রশ্ন ছোড়ে। Architect (Foundations) এর উল্টো — ছয়টি সিনারিওর ব্যাংক থেকে **চারটি** সিনারিও সামনে আসে, আর প্রশ্নগুলো সেই সিনারিওতেই যুক্ত থাকে। ছয়টি হলো:

## পুরো পরীক্ষা জুড়ে একটা প্যাটার্ন

প্রতিটি ডোমেইনে পরীক্ষা **যে সমাধানটি কাজ করে, তার সবচেয়ে সহজ রূপটিকেই** জেতে দেয়।

- সিনারিও বলছে টুল ভুল সময়ে কল হচ্ছে? উত্তর প্রায় সবসময়ই "tool description আরও স্পষ্ট লেখো" — "routing classifier যোগ করো" নয়।
- Output অসামঞ্জস্যপূর্ণ? সাধারণত "মডেলকে স্পষ্ট, মাপা যায় এমন criteria দাও" — "প্রথমটিকে যাচাই করার জন্য আরেকটি মডেল বসাও" নয়।

ঘোষিত সমস্যাটি সবচেয়ে কম যন্ত্রপাতিতে মেটায়, সেই উত্তরটি খুঁজতে শিখুন। তাতে সঠিক বাছাইয়ের হার অনেক বাড়বে।

## প্রোগ্রামে এটি কোথায় বসে

Architect (Foundations) Anthropic-এর চারটি Claude সার্টিফিকেশনের একটি — এটিই ডিজাইন-কেন্দ্রিক Foundations স্তর। যদি আপনার কাজ governance, stakeholder management আর প্রোডাকশন সিস্টেম শুরু থেকে শেষ পর্যন্ত সামলানোর দিকে যায়, Architect (Professional) স্তরটি তার জন্য বানানো। কোনোটির জন্যই অন্যটি আগে দরকার নেই।
